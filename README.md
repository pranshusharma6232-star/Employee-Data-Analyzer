# Employee Data Analyzer

## Project Description
Employee Data Analyzer is a Python-based project used to clean, analyze and visualize employee data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Features
1. Read employee data from a CSV file.
2. Remove duplicate employee records.
3. Handle missing salary values.
4. Calculate employee salary statistics.
5. Perform department-wise analysis.
6. Filter employees based on salary.
7. Display department-wise average salary graph.

## How to Run
1. Install Python.
2. Install required libraries:
   pip install pandas matplotlib
3. Open the project folder in VS Code.
4. Run main.py.
